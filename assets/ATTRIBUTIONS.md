# Asset notes

## Hero artwork

`hero-dark.webp` and `hero-light.webp` were generated for this profile on
2026-07-28 with OpenAI's built-in image generation tool. They contain no
third-party logos or readable source code.

Dark-mode prompt:

> Create an ultra-wide panoramic abstract technology banner for a senior
> software engineer focused on .NET, cloud infrastructure, AI tooling, and
> open-source engineering. Use a deep graphite-black technical space with
> restrained terminal-grid geometry, cloud-node topology, data routes, tiny
> precise particles, layered architectural lines, and electric cyan, azure,
> and subtle violet signals. Keep the composition minimal, cinematic, and
> text-free, with detail concentrated toward the outer thirds and lower edge.

Light-mode prompt:

> Create an ultra-wide panoramic abstract technology banner for a senior
> software engineer focused on .NET, cloud infrastructure, AI tooling, and
> open-source engineering. Use a soft off-white technical blueprint space with
> restrained terminal-grid geometry, cloud-node topology, data routes, tiny
> precise particles, graphite linework, and crisp cyan, azure, and subtle
> violet accents. Keep the composition minimal, editorial, and text-free, with
> detail concentrated toward the outer thirds and lower edge.

## External image services

- Social and technology badges are rendered by
  [Shields.io](https://shields.io/), with logo marks supplied through its
  supported icon catalog.
- `github-stats.svg` and `top-languages.svg` are generated inside this
  repository from Jakeuj's public GitHub API data. A scheduled GitHub Actions
  workflow refreshes them daily.
